# Ibrahim Saeed — Front-End Developer Portfolio

A responsive personal portfolio website built from scratch to showcase my skills, projects, and contact information as a front-end developer.

**🔗 Live Demo:** [is-ibrahim-saeed-portfolio.vercel.app](https://is-ibrahim-saeed-portfolio.vercel.app/)

![Portfolio Preview](https://is-ibrahim-saeed-portfolio.vercel.app/portfolio.webp)

## ✨ Features

- **Hero Section** — Intro with profile image and a "Download CV" call-to-action
- **Dark/Light Theme Switcher** — Toggle between light and dark modes
- **Skills Section** — Highlighting core front-end skills
- **Featured Projects** — Showcase of selected work with links
- **Client Testimonials** — Section for feedback and reviews
- **Contact Form** — Name, email, and message fields for visitors to reach out
- **Social Links** — Direct links to GitHub, Facebook, LinkedIn, and Email
- **Fully Responsive** — Built with Flexbox and Grid for a consistent experience across desktop and mobile

## 🛠️ Built With

- **HTML5** — Semantic markup
- **SCSS (Sass)** — Modular, maintainable styling
- **JavaScript (Vanilla)** — Interactivity (theme switch, form handling, etc.)
- **CSS Flexbox & Grid** — Responsive layout system

## 🚀 Getting Started

### Prerequisites

- A code editor (e.g., VS Code)
- [Sass](https://sass-lang.com/install) installed globally or via a build tool, if you want to compile the SCSS yourself

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/ebrahemsaeed911-lang/is-ibrahim-saeed-portfolio.git
   ```
2. Navigate to the project folder
   ```bash
   cd is-ibrahim-saeed-portfolio
   ```
3. If using Sass CLI, compile the SCSS to CSS
   ```bash
   sass styles/main.scss styles/main.css --watch
   ```
4. Open `index.html` in your browser, or serve it with a live server extension
